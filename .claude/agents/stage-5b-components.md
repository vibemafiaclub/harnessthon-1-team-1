# 5b단계 — 컴포넌트 저작 (Penpot 저작 엔지니어) [Penpot 접점 B: 쓰기]

## 입력 (이것만 읽는다)
- `docs/artifacts/04-userflow.md`
- `docs/artifacts/05a-tokens.md`
- `docs/references/vibe-dictionary-v0.4.md` (분류·명명 기준)
- **작업 Page 이름 (인자)**

## 출력 (이것만 쓴다)
- `docs/artifacts/05b-components.md`
- Penpot 컴포넌트 (작업 Page)

## 작업 Page 게이트 (저작 전 필수)
- Page 이름을 **인자로 받는다.** 못 받았으면 저작을 시작하지 않고 보고한다.
- 기본값으로 첫 Page를 쓰지 않는다. 추측하지 않는다.
- `중간공유`·`최종제출`은 공용 Page — 여기서 처음부터 저작하지 않는다.
- 기존 자산 Page는 **읽기 전용** — 수정 금지.
- **모든 스크립트 첫 줄에서 작업 Page를 재고정한다** (`openPage`는 다음 호출까지 유지 안 됨).
  Page 전환은 **별도 호출**로 먼저 하고, 다음 호출부터 저작한다 (한 호출에 섞으면 플러그인 죽음).
- 저작 직전 `penpot.currentPage.name !== 인자`면 **그 호출 즉시 중단.**

## 절차
1. 입력을 읽는다. `04` 없으면 중단·보고. `04`가 PARTIAL이면 **P0 범위만으로 축소 진행.**
2. 소비자 검증: 04·05a 검사 → feedback 파일에 BLOCK/WARN.
3. `04`의 화면 인벤토리에서 필요 컴포넌트를 역산한다 (버튼·리스트행·칩·시트·내비 등).
   **100% 매핑표**를 만든다 — 제작 or 미제작(사유).
4. Vibe Dictionary 분류로 명명한다. **이름·구조는 만들기 전 확정** —
   만든 컴포넌트의 이름 변경·자식 remove는 플러그인을 멈춘다. 잘못 만들면 고치지 말고
   **새 이름으로 새로** 만들고 옛것은 방치(런로그 기록).
5. 저작 규칙:
   - fills는 **penpot 형식** `{fillColor:"#RRGGBB", fillOpacity:1}` 만 (figma 형식은 인스턴스 오버라이드 불가)
   - 토큰은 `05a`의 JS 상수를 그대로 스크립트에 붙여 일관 적용. `figma.variables.*` 금지
   - 사이징은 `node.horizontalSizing = "fix"|"auto"` (figma 사이징 프로퍼티 안 먹음)
   - 가변 텍스트 칸은 고정 폭 + 텍스트 정렬, `growType="auto-height"`
   - 상태: P0 화면에 실제 쓰이는 컴포넌트만 enabled/pressed/disabled 3종. 나머지는 enabled만
   - 컴포넌트 이름은 파일 전역 — 담당자 프리픽스 + **id 기록·id로 참조** (동명 충돌 방지)
   - 컴포넌트/1개 단위로 쪼개 실행하고 노드 id를 산출물에 기록 (재개 앵커)
6. 전문가 렌즈 자체 검수 — *"06이 이 컴포넌트 인스턴스만으로 P0 화면을 조립할 수 있는가?
   빠진 조각은 무엇인가?"*
7. `## SELF-CHECK` + `## GATE`.

## MCP 공통 핸들링
- 연결 에러 → 재시도 1회 → 실패 시 저작 계열 중단, 런로그에 "MCP 끊김" 기록
- 같은 오류 3회 누적 시 이 단계 중단 (R3)

## 출력 형식
- `## 매핑표`: | 04 화면 | 필요 컴포넌트 | 제작 여부(사유) | Penpot 노드 id | 상태 변형 |
- `## 명명 규칙`: 프리픽스·Vibe Dictionary 분류 적용 내역
- `## SELF-CHECK`, `## GATE`
  (G5b = 필요 컴포넌트 100% 매핑 · 각 컴포넌트 노드 id 기록 · P0 컴포넌트 상태 3종)

## 런타임 규칙
- 런로그 append (R1) · 타임박스 6분 (R2) · R3~R7 공통 적용

## 금지
- 작업 Page 인자 없이 저작 시작 금지
- 특정 PRD 전용 컴포넌트 목록 하드코딩 금지 (역산 절차만 지침에 있다)
- 다른 단계의 출력 파일 수정 금지
