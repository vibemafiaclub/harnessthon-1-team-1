## 잘 쓴 부분 (그대로 활용)

- **"과업 → 화면 시퀀스 → 결정적 UI → 전환 트리거"** 형식 → 4단계 플로우맵의 `──[트리거]──>` 표기법을 이 형식에서 그대로 계승했다.

- 키움 "키우GO 시장온도계"를 **반례(참고용)**로 명시해준 점 → PRD §4 "정답 하나를 내려주는 화면으로는 안 됩니다"를 `New/Discover`에서 무엇을 하지 말아야 하는지로 번역할 수 있었다. 반례를 반례로 표기한 건 03의 잘한 판단.
