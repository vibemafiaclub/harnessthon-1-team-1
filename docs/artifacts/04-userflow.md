근거를 못 댄 화면(계좌 개설·잔고/포트폴리오 전용 화면·뉴스 전체 피드·커뮤니티 등)은 PRD에 문장이 없어 **만들지 않았다.**

### 저작 순서 권고 (5·6단계 인계)
`P0 4개 → P1 10개 → P2 4개` 순으로 저작하고, 타임박스가 부족하면 **P2부터 버린다**.
P0 4개는 PRD §6이 "최소 3개"로 지정한 `New/Watchlist` · `New/StockDetail` · `New/Discover` + §6-2가 오버레이로 명시한 `New/OrderSheet`이므로 **어떤 경우에도 컷 대상이 아니다.**
상태 화면(`-Empty`/`-NoStyle`/`PriceLoading`/`-Dense`/`-Digest`)과 실패 화면은 `shape.clone()`으로 원본 화면을 복제한 뒤 덮을 것만 얹는 방식이 전제다(AGENTS.md 저작 힌트).
