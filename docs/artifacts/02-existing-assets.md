### 폰트 가용성

이번 실행은 시간 예산상 `penpot.fonts.all` 조회를 생략했다(속도 우선 지시). 원본 폰트는
`Spoqa Han Sans Neo`(본문 전반), `SF Pro`(상태바 시계, 시스템 목업용)이다. **다음 단계에서
`penpot.fonts.all`로 서버 가용 여부를 반드시 확인**하고, 없을 경우 국문 대응 산세리프
(예: Pretendard, Noto Sans KR) 를 대체 후보로 검토할 것.

## 톤앤매너 요약 (3~5줄)

- 신규 화면이 **지켜야 할 것**: 배경 3단계 위계(기본/서페이스), 텍스트 4단계 명도 위계, 브랜드 블루(#4880EE)를 유일한 액센트로 쓰는 절제된 컬러 사용, 카드·큰 요소에 radius 20을 쓰는 굵은 라운드 스타일, 리스트 행(아이콘+라벨+값)·상단 헤더·하단 탭바 3종 반복 패턴을 컴포넌트로 재사용.
- 신규 화면이 **정돈해야 할 것**: 라이트모드 전환 시 다크 전용 톤(#101012, #17171B, #1F2026 등)을 그대로 쓰지 말고 위 매핑표대로 반전 적용할 것. 간격 값이 22/17/7/13처럼 8pt 그리드에서 다소 벗어나 있으므로, 다음 단계(토큰 확정)에서 4px 배수 스케일로 근사 정리하는 편이 일관성에 유리함.
- 상태바(SF Pro, "9:41")는 OS 목업 요소이므로 실제 서비스 화면 컴포넌트로 이식하지 말 것.
