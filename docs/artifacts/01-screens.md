# 01 - 화면 요구사항

> 포지션: 금융 앱이 자산·혜택·송금을 한 화면에서 끝내던 문법으로, 여행 예약은 목적지를 못 정한 사람의 검색창 앞 멈춤과 이미 표를 끊은 사람의 메뉴 파고들기를 없앤다.

## 제품 요약
- 도메인: 항공권 검색/예약을 중심으로 한 종합 여행 예약 서비스 (투어·체험·입장권 포함)
- 대상 사용자: 날짜/목적지가 정해진 검색형 사용자, 목적지 미정 상태로 싼 표를 구경하는 사용자, 이미 표를 끊고 현지 투어를 찾는 사용자, 구매 보류 후 가격 알림을 원하는 사용자, 비슷한 항공권을 비교해 결정하려는 사용자 (3장)
- 기존 자산 Page 이름: `3-toss` (홈-자산요약, 혜택, 전체메뉴, 상세 4개 화면, 읽기 전용) (2장)
- 프레임 네이밍 규칙: 신규 화면 최상위 프레임 이름은 `New/` 로 시작 (`New/Home`, `New/Results`), 신규 화면은 `3-toss-result` Page에 저작 (7장)
- 화면 폭: 390 (라이트모드, 모바일 앱), 세로는 내용에 맞게 확장 (7장, run 특수 지시)

## 화면별 상세 스펙

### S01 New/Home (P0)
- 목적: 검색형/목적지 미정형/재방문 여정 확인형 사용자가 각자 다음 행동을 즉시 찾는다.
- 필수 요소(근거): 항공권 검색 진입 - 출발지, 목적지, 날짜, 인원 (5-1절) / 예정된 여정 - 출발까지 D-day, 목적지 투어·체험·입장권 제안 (5-1절) / 둘러보기 묶음 - 테마·할인율·마감임박·땡처리 갈래 (5-1절, 갈래는 임의 지정 허용) / 담아둔 목적지 - 가격 하락 알림 대상 (5-1절, 3-2절) / 하단 주요 이동 수단 (5-1절)
- 섹션 순서(위에서 아래):
  1. 상단 검색 진입 카드(출발지-목적지-날짜-인원)
  2. 예정된 여정 카드 목록 (D-14 이내, 없으면 빈 상태)
  3. 둘러보기 묶음 (갈래별 가로 스크롤 카드)
  4. 담아둔 목적지 목록 (없으면 빈 상태)
  5. 하단 탭 내비게이션
- 더미 데이터 예시:
  - 검색 진입 카드: "서울(인천) 출발" / "도쿄(나리타) 도착" / "8월 15일 목요일, 3박" / "성인 2명"
  - 예정된 여정: "오사카 여행까지 9일 남음" 카드 + 추천 "오사카 유니버설 스튜디오 입장권", "도톤보리 야시장 투어"
  - 둘러보기 묶음 갈래: "이번 주 특가" / "마감 임박" / "70퍼센트대 할인 땡처리" / "가을 단풍 여행지"
  - 둘러보기 카드 예: "다낭 왕복 항공권, 정가 대비 42퍼센트 할인, 19만 8천원부터"
  - 담아둔 목적지: "방콕, 담아둔 뒤 최저가 21만원, 3만원 하락 시 알림"

### S02 New/Home 빈 상태 (P1)
- 목적: 처음 앱을 연 사용자에게 예정 여정/담아둔 목적지가 비어 있음을 알리고 첫 행동을 유도한다.
- 필수 요소(근거): 예정된 여정 빈 상태 문구, 담아둔 목적지 빈 상태 문구 (4절 "예정된 여정도, 담아둔 목적지도 하나도 없습니다")
- 섹션 순서: 검색 진입 카드 → 예정된 여정 빈 상태(문구+검색 유도 CTA) → 둘러보기 묶음(동일 노출) → 담아둔 목적지 빈 상태(문구+둘러보기 유도 CTA) → 하단 탭
- 더미 데이터 예시: "아직 예정된 여정이 없어요, 지금 항공권을 검색해보세요" / "담아둔 목적지가 없어요, 마음에 드는 곳을 담아두면 가격이 떨어질 때 알려드려요"

### S03 New/Results (P0)
- 목적: 검색 결과 다수 항공편 중 조건에 맞는 한 편을 골라 결정까지 간다.
- 필수 요소(근거): 항공편 목록 - 출발/도착 시각, 소요시간, 경유여부, 항공사, 가격 (5-2절) / 경유 구간 표현 - 경유지, 대기시간 (5-2절) / 출발일 앞뒤 가격 비교 (5-2절) / 조건 좁히기 진입점 - 직항여부, 시간대, 항공사 (5-2절) / 비교함 진입점 - 최대 3개 (5-2절, 4절) / 운임 등급 선택 진입점 (5-2절)
- 섹션 순서(위에서 아래):
  1. 상단 검색 조건 요약 바 + 조건 좁히기 진입점
  2. 날짜별 최저가 스트립 (검색일 앞뒤 7일)
  3. 정렬/비교함 진입점 바 (담긴 개수 표시, 최대 3개)
  4. 항공편 목록 (행마다 항공사, 출발-도착 시각, 소요시간, 경유 여부, 가격, 담기 버튼, 경유 시 경유 구간 타임라인 표시)
  5. 행 탭 시 운임 등급 시트(S06) 오픈
- 더미 데이터 예시:
  - 조건 요약 바: "인천 to 도쿄(나리타), 8월 15일, 성인 2명"
  - 최저가 스트립: "8/13 목 21만원 / 8/14 금 23만원 / 8/15 토 26만원 / 8/16 일 24만원 / 8/17 월 20만원"
  - 항공편 행 1: "한별항공 KH205, 인천 09:20 출발, 나리타 11:45 도착, 소요 2시간 25분, 직항, 26만 4천원"
  - 항공편 행 2(경유): "청람항공 CR812, 인천 06:10 출발, 나리타 13:50 도착, 소요 7시간 40분, 오사카 간사이 경유 3시간 10분 대기, 19만 9천원"
  - 비교함 진입점: "비교함 2개 담김, 최대 3개"

### S04 New/Results 로딩 (P1)
- 목적: 실시간 요금 수신 대기 동안 이탈을 막고 진행 중임을 알린다.
- 필수 요소(근거): 항공편 행 스켈레톤, 최저가 스트립 스켈레톤 (4절 "불러오는 데 몇 초가 걸리고")
- 섹션 순서: 조건 요약 바(즉시 표시) → 최저가 스트립 스켈레톤 → 정렬/비교함 바(비활성) → 항공편 행 스켈레톤 6~8개
- 더미 데이터 예시: "항공권을 찾고 있어요" 안내 문구, 행 스켈레톤은 회색 블록으로 텍스트 없음

### S05 New/Results 0건 (P1)
- 목적: 조건을 너무 좁혀 결과가 없을 때 조건 완화를 유도한다.
- 필수 요소(근거): 0건 안내, 적용 조건 요약, 조건 다시 열기/초기화 (4절 "맞는 항공편이 한 건도 없는 경우")
- 섹션 순서: 조건 요약 바 → 최저가 스트립(대안 날짜 강조) → 0건 안내 블록(문구+조건 요약+CTA 2개)
- 더미 데이터 예시: "조건에 맞는 항공편이 없어요" / "적용된 조건: 직항, 오전 출발, 한별항공" / CTA "조건 다시 설정" "조건 초기화"

### S06 New/Results/FareSheet (P1)
- 목적: 같은 항공편의 운임 등급별 환불/변경/수하물 조건을 비교해 하나를 고른다.
- 필수 요소(근거): 운임 등급 목록과 조건 차이, 선택 CTA (5-2절 "별도 화면이 아니라 이 화면 위에 올라오는 형태")
- 섹션 순서: 시트 핸들 + 선택한 항공편 요약 → 운임 등급 카드 목록(가격 낮은 순) → 각 카드 내 환불/변경/수하물 조건 → 선택 CTA(하단 고정)
- 더미 데이터 예시:
  - "이코노미 라이트, 19만 9천원, 환불 불가, 변경 수수료 5만원, 수하물 미포함"
  - "이코노미, 23만 4천원, 출발 전 환불 가능(수수료 3만원), 변경 1회 무료, 수하물 15kg"
  - "이코노미 플렉스, 27만 8천원, 환불 수수료 없음, 변경 무제한 무료, 수하물 20kg"

### S07 New/Results/CompareSheet (P2, 생략 가능)
- 목적: 비교함에 담은 항공편을 나란히 보고 최종 선택한다.
