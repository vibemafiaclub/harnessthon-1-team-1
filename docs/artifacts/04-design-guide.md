# 04 — 디자인 가이드 (run-02, 30분 압축 실행)

## 방향
- **라이트모드 모바일 앱** (사용자 지시). 기존 `3-toss` Page 실측 결과 이미 라이트 톤(흰 서페이스 + 잉크 `#17171b`)이라 톤앤매너 유지와 충돌 없음.
- 폭 390 고정, 세로 가변. 폰트는 서버에 Spoqa Han Sans Neo가 없어 **Noto Sans KR**로 대체(전 웨이트 보유).

## 실측 근거 (`3-toss` 홈 보드 fills 빈도)
`#ffffff`(11) `#e4e4e5`(10) `#17171b`(7) `#2c2c34`(6) `#62626c`(6) `#9e9ea3`(5) `#c3c3c6`(5) `#4880ee`(2) `#f4b64f`(1) `#dee9fd`(1)

## TOKENS (JS 상수 — 6·7단계가 그대로 붙여넣어 사용)

```js
const T = {
  bg:        "#F4F5F7",   // 화면 배경 (라이트 그레이)
  surface:   "#FFFFFF",   // 카드·시트

  ink:       "#17171B",   // 제목 (실측 유지)
  ink2:      "#62626C",   // 본문 보조 (실측 유지)
  ink3:      "#9E9EA3",   // 캡션 (실측 유지)
  blue:      "#4880EE",   // 브랜드 (실측 유지)
  blueSoft:  "#DEE9FD",   // 블루 배경칩 (실측 유지)
  orange:    "#F4B64F",   // 액센트·특가 (실측 유지)
  red:       "#E5503C",   // 마감·에러

  r:  { card: 16, chip: 999, btn: 12, sheet: 24 },
```

## 컴포넌트 스펙 (핵심만)
- **FlightRow**: surface 카드 r16, 내부 — 항공사(13/ink2) · 출발-도착 시각(17/700) · 소요/경유(13/ink2) · 가격(17/700 우측) · 비교담기 버튼
- **Chip**: r999, 기본(surface+divider stroke/ink2) · 선택(blue bg/white)
- **FareCard**: 운임 등급 카드 r12 — 등급명·조건 3줄·가격, 선택 시 blue stroke 2
- **DateStrip 셀**: 날짜(13) + 최저가(13/700), 선택일 blue
- **StopBar**: 경유 타임라인 — 구간 바(blue) + 대기 바(divider) + 경유지 라벨(11)
- **PrimaryButton**: blue bg, r12, white 17/700

## 상태 규칙
- 로딩: 텍스트 대신 divider 색 라운드 사각형(스켈레톤)
- 0건: 아이콘 없는 안내 문구 + 조건 초기화 버튼
- 마감(에러): red 라벨 + 대체 항공편 제안
