# 3단계 — 경쟁사 분석

입력: `docs/PRD.md` (당근마켓 팀의 증권 서비스 — 투자 초심자 대상 "관심종목→매수" 경험 설계 과제)

도메인: 국내 모바일 증권 트레이딩 앱(MTS). PRD 3절 유저스토리(관심종목 훑기·종목 판단·주문·발견)를
그대로 겪게 하는 실사용 앱을 대상으로 선정했다.

## 선정

기준: **활성 사용자 수(MAU) 상위**. 국내 증권 앱은 두 갈래로 나뉜다 — ① 와이즈앱·리테일이
매월 발표하는 "증권 거래 전용 앱" 표본조사(전통 MTS), ② 슈퍼앱에 내장된 증권 섹션(토스증권)은
별도 집계되어 ①에는 잡히지 않지만 자체 MAU가 더 크다. 두 출처를 병기해 상위 5개를 선정했다.

| 앱 | 선정 지표(값) | 소스 |
|---|---|---|
| 토스증권 (토스 앱 내 섹션) | MAU 약 410만~550만명 (2025-07 ~ 2026-02, 보도 시점별 상이) — 증권 전용 앱이 아니라 슈퍼앱 내 섹션이라 ①표본조사엔 미포함, 별도 집계 기준 국내 최대 | 언론보도 종합: 파이낸셜뉴스(2026-07-21), 헤럴드경제, 아주경제(2026-07-29) — WebSearch 조사 |
| 미래에셋증권 M-STOCK | MAU 360만명 (2026-01, 국내 1위) | 와이즈앱·리테일 표본조사 (wiseapp.co.kr/insight/detail/920, 매드클럽·뉴시스 인용) |
| 키움증권 영웅문S#(NEW) | MAU 343만명 (2026-01, 국내 2위) + 자체 표기 "대한민국 주식시장 점유율 1위"(위탁매매 기준, 21년 연속) | 와이즈앱·리테일 표본조사 + App Store 공식 리스팅 |
| 삼성증권 mPOP | MAU 284만명 (2026-01, 국내 3위) | 와이즈앱·리테일 표본조사 |
| 한국투자증권 (한투 MTS) | MAU 265만명 (2026-01, 국내 4위) | 와이즈앱·리테일 표본조사 |

## 수집 소스 기록

폴백 사다리를 순서대로 시도했다.

| 단계 | 결과 |
|---|---|
| ① uibowl.io | **실패** — WebFetch 시 페이지 콘텐츠 비어있음(JS 렌더링 필요 추정). 다음 단계로 이동 |
| ② Mobbin | **실패** — MCP 응답 "Mobbin MCP requires a paid plan". 재시도 없이(유료 게이트는 재시도로 안 풀림) 다음 단계로 이동 |
| ③ 앱스토어 공식 스크린샷 | **성공** — iTunes Search/Lookup API(`itunes.apple.com`, country=kr)로 5개 앱의 공식 스크린샷 원본 URL을 얻어 전부 다운로드. 앱당 6~9장 확보, 그중 유저스토리와 관련된 3~4장씩을 골라 검수 |
| ④ 공식 사이트·블로그 | **보조 사용 1건** — 토스증권 매수 주문 시트(비율 퀵버튼)는 앱스토어 스크린샷에 노출되지 않아, WebSearch로 찾은 UX 분석 블로그(brunch.co.kr) 텍스트 인용으로 대체. 이 항목은 이미지 없이 텍스트 리서치임을 아래 원장에 명시 |
| ⑤ 유튜브 리뷰 프레임 | 미시도 — ③에서 4/5개 앱의 핵심 화면을 충분히 확보해 타임박스 내 불필요 판단 |

다운로드한 이미지는 `docs/artifacts/images/{toss,miraeasset,kiwoom,samsung,hantu}/` 아래 저장.
전 파일 `curl`/`urlretrieve` 후 바이트 크기 확인 — 0바이트·깨짐 없음(전량 100KB~900KB 정상 PNG/JPG). 재다운로드 불필요.

## 유저플로우

PRD 3절의 4개 핵심 유저 스토리 각각에, 그 과업을 가장 잘 보여준 경쟁 앱 화면 시퀀스를 매칭했다.

### 과업 1 — "관심 있는 종목을 모아두고 등락을 한눈에 확인하고 싶다"

**삼성증권 mPOP**
`앱 실행 → MY(홈)` **[트리거: 로그인 완료 시 자동 진입]** `→ 하단 탭바 '관심종목' 탭` **[트리거: 하단 5탭 네비 중 '관심종목' 탭]** `→ 관심종목 리스트`
- MY(홈) 결정적 UI: 총자산 카드("총 자산 423,000,000원", 은행/증권 분리) + 하단 5탭 네비(`MY·관심종목·주식현재가·종합차트·주식잔고·메뉴`)
- 관심종목 리스트 결정적 UI: 종목찾기 화면에서 확인된 별표(★) 즐겨찾기 토글 — 탭하면 관심종목에 즉시 추가/해제(별도 확인 다이얼로그 없음)

**미래에셋증권 M-STOCK**
`홈 → 하단 하트 아이콘 '관심종목' 탭` **[트리거: 하단 아이콘 탭]** `→ 관심종목 리스트`
- 결정적 UI: 종목행 3열 구성 — `로고+종목명` · `스파크라인 미니차트`(빨강=상승/파랑=하락 배경) · `등락률%+거래량 숫자`. 색만으로 상승/하락을 구분하지 않고 스파크라인 방향까지 이중으로 보여준다.

**한국투자증권 MTS**
별도 화면 진입 없이 `홈(MY) → '국내'/'해외' 탭 전환` **[트리거: 상단 세그먼트 탭]** 만으로 홈 안에 상시 노출된 `최근/관심` 섹션에 도달 — 관심종목을 "별도 페이지"가 아니라 "홈의 한 섹션"으로 축소한 설계.
- 결정적 UI: `최근/관심` 리스트 + 종목당 `현재가 · 등락액 · 등락률` 3분할, 리스트 하단 `더보기` 링크로 전체 관심종목 화면 진입

### 과업 2 — "종목의 가격 흐름과 기본 정보를 보고 판단하고 싶다"

**미래에셋증권 M-STOCK** (가장 완결된 상세 화면 확보)
`관심종목 리스트 → 종목행 탭` **[트리거: 리스트 아이템 탭]** `→ 종목상세 화면`
- 결정적 UI: 상단 초대형 폰트 `현재가 + 등락률`(빨강/파랑) 바로 아래 `HOME · 호가 · 차트 · 시세 · 뉴스 · 토론실` 탭 스트립 + 화면 우상단에 항상 떠 있는 검정 `주문` 버튼(스크롤해도 고정)
- 차트 영역에는 이동평균선 전환(`5·20·60·120`) 칩이 차트 바로 위에 위치 — PRD가 요구한 "기간 전환" 요소와 동일 패턴

**키움증권 영웅문S#**
동일 화면 하단에 호가창이 인라인으로 노출(`글로벌전광판`과는 별개 화면)
- 결정적 UI: 10단 호가 리스트, 매도잔량(파랑)·매수잔량(빨강) 컬러 바 + 막대 길이로 잔량 비율 시각화

### 과업 3 — "수량과 가격을 입력해 주문하고 그 결과를 확인하고 싶다"

**미래에셋증권 M-STOCK**
`종목상세 화면 → 우상단 '주문' 버튼 탭` **[트리거: 고정 버튼 탭]** `→ 주문 시트(화면 위 오버레이로 등장, 별도 페이지 전환 없음)`
- 결정적 UI: '주문' 버튼이 스크롤 위치와 무관하게 항상 같은 자리에 고정 — PRD가 명시한 "하단 고정 액션" 요구와 정확히 대응

**토스증권** *(화면 캡처 미확보 — 텍스트 리서치로 대체, 아래 표기 참조)*
`종목상세 화면 → '매수' 버튼 탭` `→ 주문 시트` `→ 수량/비율 선택` `→ 주문 확정`
- 결정적 UI(텍스트 리서치 근거): 금액 직접입력 대신 `10% · 25% · 50% · 최대` 비율 퀵버튼 + "이 주문 시 OOO가 내 자산의 20%가 됩니다" 안내문 — 초심자가 "얼마"가 아니라 "내 자산 대비 얼마나"로 판단하게 설계
- ⚠️ **SKIPPED**: 이 화면의 실제 스크린샷은 uibowl.io(실패)·Mobbin(결제벽)·App Store(증권 화면 미노출)·블로그 이미지(비교 목적의 타사/AI 목업이라 확증 어려움) 전부에서 확보 실패. R3에 따라 재시도 1회(블로그 검색) 후 항목만 SKIPPED 처리하고 텍스트 인용으로 남김.

**공통 관찰**: 5개 앱 모두 주문 확정 후의 "성공/실패 결과 화면"(PRD 5절: 잔고 부족·장 마감 실패 케이스 포함)은 앱스토어 마케팅 스크린샷에 노출되지 않는다(마케팅 자료의 구조적 한계). ⚠️ **SKIPPED** — 5개 앱 전부, 재시도(텍스트 리서치) 후에도 확보 실패. 이 상태 화면은 하네스 4단계(유저플로우/화면 설계) 담당이 PRD 5절 요구사항으로 직접 설계해야 한다.

### 과업 4 — "무엇을 살지 못 정한 사용자가 지금 살 만한 종목을 찾고 싶다" (가장 큰 이탈 지점)

**키움증권 영웅문S# — AI 자산관리(키우GO)**
`홈 → 메뉴/배너 '키우GO' 진입` **[트리거: 홈 배너 탭]** `→ AI 자산관리 화면`
- 결정적 UI: "가 보는 시장" 시장온도계 게이지(`-50 침체 ~ +50 과열`, 바늘로 현재값 `-12.69` 표시) — 수십 개 지표 대신 게이지 하나로 "지금 사도 되나"를 대신 판단해준다. PRD 4-2절 "정답 하나를 내려주는 화면으로는 안 된다"는 요구와는 반대 극단의 레퍼런스(참고용 반례)로 유용.

**미래에셋증권 M-STOCK — 투자NOW**
`홈 → 하단 '뉴스' 탭` **[트리거: 하단 네비 탭]** `→ 투자NOW 화면`
- 결정적 UI: `개인맞춤` 토글 스위치(주황, 기본 ON) — 끄면 전체 뉴스, 켜면 보유/관심종목 연관 뉴스로 실시간 필터링. PRD가 요구한 "선택이 추천에 실제로 반영되는 것처럼 보이게"의 가장 단순한 구현형.

**삼성증권 mPOP — 통합검색**
`홈 → 상단 검색 아이콘 탭` **[트리거: 아이콘 탭]** `→ 통합검색 화면`
- 결정적 UI: `사람들이 많이 찾아보는` 랭킹 리스트(1~6위, `NEW`/상승·하락 화살표 배지) — 검색어를 몰라도 순위만 보고 따라 들어갈 수 있다. PRD 4절 "정답 하나 대신 사용자가 고르게"와는 결이 다른, "군중이 이미 고른 것"을 보여주는 접근.

**토스증권 — 발견 탭** *(화면 내부 미확보)*
`토스증권 홈 → 탭바 '발견' 탭` **[트리거: 탭바 4개 탭 중 3번째]** `→ 발견 화면`
- ⚠️ **SKIPPED**: 탭 존재(라벨 "발견")는 앱스토어 스크린샷으로 확인했으나 탭 내부 화면은 확보 실패. 재시도(블로그 검색) 후에도 실패 — SKIPPED 처리.
